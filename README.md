# MTcord

Part of Mick's Tools.

A browser extension for browsing, exporting, downloading and deleting Discord messages.

## Features

- Server and direct-message scopes
- Multi-channel server search
- Message content and date filters
- Filters for your messages, media and files
- Incremental loading with complete-match selection
- JSON export with one file per channel
- Separate media and file downloads
- Ownership-validated deletion of your own messages
- Cancellation, progress and partial-failure reporting
- Dark, light and system appearance
- Responsive layout
- Chromium and Firefox builds

## Installation

Download the browser packages from the [GitHub releases](https://github.com/micknorj/MTcord-extension/releases) page. Use the named MTcord package for your browser; the source code archives generated by GitHub are not extension packages.

### Chromium

1. Download `MTcord-v0.1-chromium.zip` from the latest release.
2. Extract the ZIP file.
3. Open `chrome://extensions` or the equivalent extensions page.
4. Enable Developer mode.
5. Choose **Load unpacked** and select the extracted folder.

Extensions installed in Developer mode must be updated manually.

### Firefox

The current Firefox package is intended for temporary testing while the extension remains unsigned.

1. Download `MTcord-v0.1-firefox.zip` from the latest release.
2. Extract the ZIP file.
3. Open `about:debugging#/runtime/this-firefox`.
4. Choose **Load Temporary Add-on** and select `manifest.json` from the extracted folder.

Firefox removes temporary add-ons when the browser closes. Permanent installation in standard Firefox requires a package [signed by Mozilla](https://extensionworkshop.com/documentation/publish/signing-and-distribution-overview/).

## Usage

Open Discord in the browser and sign in before opening MTcord from the browser toolbar.

Connect to the existing session, choose a server or direct message, select the search scope and apply any filters. Search results can then be selected for JSON export, attachment download or deletion.

Deletion is limited to messages owned by the signed-in Discord account and requires confirmation.

## Privacy

MTcord reads the existing Discord browser session only after you connect. Session credentials, message results, selections, appearance and operation state remain in memory and are not stored by MTcord.

MTcord has no analytics, telemetry, advertising, accounts or intermediary server.

Network requests are limited to Discord and Discord-hosted attachments required for the actions you request.

## Security

- No token-entry interface
- No credential logging or export
- No raw message HTML rendering
- Exported filenames are sanitized for Windows and protected against path traversal
- Destructive operations validate message ownership immediately before deletion
- Rate limits are handled automatically
- Ambiguous deletion failures are not retried automatically
- Attachment downloads have a 512 MB in-memory limit per operation

See the [security policy](SECURITY.md) for the full security model.

## Permissions

- `activeTab`: identifies the Discord tab used to open MTcord
- `discord.com`: reads the existing session and communicates with Discord
- `cdn.discordapp.com` and `media.discordapp.net`: previews and downloads Discord-hosted attachments

MTcord does not request access to all websites, browsing history or cookies.

## Limitations

- Desktop Chromium and Firefox browsers only
- Browser-store packages are not currently available
- Manually installed Chromium packages do not update automatically
- The current Firefox package is temporary and unsigned
- Discord must already be open and signed in
- Discord may change its private user-session API or session storage without notice
- External embedded media is not downloaded
- Threads and forums do not have dedicated management tools
- Downloads are limited to 512 MB in memory per operation
- Discord may limit searches, access or automated user-account actions
- Automated tools used with a normal Discord account may conflict with [Discord's Terms of Service](https://discord.com/terms) or policies and may carry account risk

## Development

Install [Node.js](https://nodejs.org/) 22.18 or later. From the repository root:

```sh
npm ci
npm test
npm run typecheck
npm run audit:prod
npm run package
```

The packaged browser builds are written to `packages`.

For interface development:

```sh
npm run dev
```

The development server cannot read a Discord session. Use an unpacked extension build for live Discord testing.

Package name: `micknorj.tools-mtcord`

Firefox add-on ID: `@micknorj.tools-mtcord`
